How To Activate The TabTimer From The Search Bar?

Chrome Extention

currently not ready yet for the webstore

Chrome Settings

  • go to: chrome://settings/searchEngines
  • under "default search engines", click on ADD
  • insert this URL: https://yoavdim.bitbucket.io/simple-example/index.html?val=%s
    you can select your own name and keyword, for this example I used:
  • all done. now open a tab (ctrl+T), click on the search bar(or press f6 or ctrl+L), type the keyword (here: _timer), press the space key, and insert the time
  • if you want to count up: type "stopper"
  • when the browser extention will be ready, this process will be improved, and will also work offline.
